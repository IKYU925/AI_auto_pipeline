# 0010. 1단계 A/B 본 실험은 조건마다 1회만 실행한다

상태: 채택
날짜: 2026-11-14

## 맥락

plan.md 7장은 13개 시나리오를 조건마다 3회 반복(약 78회)하고, 반복 간 범위가 겹치면 "차이 없음"으로 보도록 정했다. 실제 API 호출은 사용자 비용이 들고, 사용자는 실제 호출을 꼭 필요한 중요 테스트에만 쓰라고 했다.

## 결정

조건 A와 B를 각각 1회(13개 시나리오)만 실행한다. 조건마다 `--max-usd 4`를 건다.

## 근거

- A/B 비교는 1단계의 핵심 주장(최적화 묶음의 비용 효과)이라 빼지 않는다.
- 첫 실행의 비용(S01 $0.08, 조건 A 13건 $0.82)으로 보면 3회 반복은 1회 대비 비용만 3배가 되고, 질문(최적화가 비용과 정확도를 바꾸는가)에는 1회로도 답할 수 있다(추정).

## 영향

- plan.md 7장의 범위 규칙을 쓸 수 없다. 결과는 단일 실행 값으로 보고하고, 차이가 작으면 판단을 보류한다.
- LLM 결과는 실행마다 달라질 수 있다. 같은 시나리오의 결과가 A와 B에서 다르면 최적화 때문인지 우연인지 1회로는 가릴 수 없다.
- 필요하면 특정 시나리오만 골라 반복한다(예: A와 B에서 결과가 갈린 시나리오).

## 검토한 대안

- 계획대로 3회 반복: 비용 3배.
- B를 건너뛰기: 1단계의 핵심 비교를 잃는다.
