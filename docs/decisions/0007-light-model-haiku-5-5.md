# 0007. 경량 모델은 claude-haiku-5-5, temperature는 보내지 않는다

상태: 채택
날짜: 2026-11-14

## 맥락

Day 1에 `claude-haiku-5-5`를 없는 모델로 보고 `claude-haiku-4-5`로 바꿨다. 근거로 쓴 모델표가 2026-09 기준이었다. 실제 키로 모델 목록 API를 조회하니 `claude-haiku-5-5`(2026-10-07)가 있었다.

## 결정

- 경량 모델(분류, 요약)은 `claude-haiku-5-5`, 고성능 모델(원인 분석, 수정 생성)은 `claude-opus-5-5`.
- 요금은 요금 페이지 기준 Haiku 5.5 입력 0.10, 출력 0.50 USD, Opus 5.5 입력 4, 출력 20 USD(100만 토큰당).
- 어느 Anthropic 모델에도 temperature를 보내지 않는다.

## 근거

- Haiku 5.5는 Haiku 4.5보다 10배 싸고, 원래 기획의 의도와 같다.
- Opus 5.5, Sonnet 5.5, Fable 5.x는 기본값이 아닌 temperature를 400으로 거절한다. Haiku 5.5는 크레딧 부족으로 확인하지 못했다. 확인하지 못한 위험을 없애려고 모든 모델에서 뺐다.
- 결과의 흔들림은 시나리오당 3회 반복과 범위 보고(plan.md 7장)로 다룬다.

## 영향

- 장애당 비용 추정이 바뀐다. 분류 비용이 크게 줄어 A/B 차이에서 모델 분리의 몫이 커질 수 있다(추정).
- Haiku 5.5의 프롬프트가 10만 토큰을 넘으면 요금이 5배가 된다. 지금 프롬프트는 수천 토큰 수준이라 해당하지 않는다(추정, 첫 실행의 토큰 수로 확인).

## 검토한 대안

- Haiku 4.5 유지: 비싸고 이전 세대다.
- 모델별로 temperature 허용 목록 관리: 새 모델이 나올 때마다 틀릴 수 있다.
