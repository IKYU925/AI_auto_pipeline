# 작업 기록

세션마다 결정 하나를 한 줄로 남긴다. 열은 시각(UTC), 단계, 결정, 이유, 근거(PR, 커밋, 파일), 결과다. GitHub에서 표로 보인다.

- 기록은 고치지 않고 덧붙인다. 틀린 판단은 새 줄로 대체한다(예: 2026-11-14.tsv의 haiku 모델 판단).
- 계획을 바꾸거나 여러 기능에 걸친 결정은 [decisions](../decisions/README.md)에도 남긴다.
- [2026-11-14.tsv](2026-11-14.tsv)의 시각은 세션이 끝난 뒤 커밋과 PR 병합 시각으로 복원했다. 분 단위는 근사값이다.
