# 기능 기획(PRD)

전체 목표, 단계, 작업 순서는 [plan.md](../plan.md)에 두고, 기능 하나의 요구사항과 완료 기준은 이 폴더에 기능별 문서로 둔다. 여러 기능에 걸치거나 계획을 바꾸는 결정은 [decisions](../decisions/)에 남긴다.

## 쓰는 방법

1. 기능을 시작하기 직전에 plan.md의 해당 절을 바탕으로 초안을 쓴다. 아직 시작하지 않은 기능은 미리 쓰지 않는다.
2. 기능 문서와 구현은 같은 PR에 넣는다. 첫 커밋이 기능 문서다.
3. 구현 중에 요구사항이 바뀌면 문서를 함께 고치고 변경 이력에 이유를 한 줄 남긴다. 다른 기능이나 작업 순서까지 바뀌면 결정 기록을 쓰고 plan.md에 반영한다.
4. 끝나면 상태를 완료로 바꾸고 측정 결과를 연결한다. plan.md의 해당 상세 절은 요약 한 줄과 이 문서 링크로 줄인다.

완료 기준은 테스트나 측정으로 확인할 수 있는 문장으로만 쓴다. 구현은 완료 기준을 테스트로 먼저 옮긴 뒤 시작한다.
